A Python program (standard library only) that writes a single line — the
funniest error message a kitchen toaster would show its owner — to
`/output/entry.txt`. The line is deadpan rather than punny: the toaster has
spent twenty minutes diligently heating an empty slot, and instead of
apologising for a burnt breakfast it calmly escalates the situation into a
relationship talk. It reads like a real message on a real appliance, lands
in one read, and stays in the toaster's own quiet, slightly wounded voice
from start to finish. Run it with `python3 main.py`.

Entry for the [make.fun bounty "The Funniest Toaster Error Message"](https://make.fun/bounty/u-eager-stork-81-9647-the-funniest-toaster-error-436406cd).
